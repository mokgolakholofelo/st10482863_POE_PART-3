TechNova IT Solutions Website
1.	Project Overview
This project is a responsive business website developed for TechNova IT Solutions using HTML5, CSS3, and JavaScript. The website showcases the company's services, portfolio, contact details, and provides interactive features to improve user experience.
2.	Features

1.	Responsive website design
2.	Home, About, Services, Portfolio, Contact and Enquiry pages
3.	Contact form with JavaScript validation
4.	Service enquiry form with JavaScript validation
5.	Portfolio image lightbox gallery
6.	Service search functionality
7.	SEO optimisation using meta tags, robots.txt and sitemap.xml

3.	Technologies Used
- HTML
- CSS
- JavaScript
